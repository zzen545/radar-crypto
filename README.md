# Radar Tren Crypto

Dashboard analisa tren crypto (BULLISH / SIDEWAYS / BEARISH) yang berjalan langsung di browser.
Data diambil live dari Binance, dengan cadangan Bitget untuk koin yang tidak ada di Binance
(mis. XAU, LIT). Indikator: MA20/50/200, RSI, MACD, Bollinger Bands, volume.

**Buka dashboard:** https://zzen545.github.io/radar-crypto/

- `index.html`: dashboard web (satu file, tanpa server).
- `python/`: versi command line (Python) dengan logika analisa yang sama.

> Ini analisa teknikal otomatis, bukan saran investasi.
